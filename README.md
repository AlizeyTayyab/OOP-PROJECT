 🎮 Tower Defense Game (OOP Project)

A 2D Tower Defense game developed in C++ using SFML.  
This project demonstrates Object-Oriented Programming (OOP) concepts and graphical game development.

---

 🎯 Project Purpose

The main objective of this project is to implement and demonstrate:

- Inheritance  
- Polymorphism (runtime)  
- Encapsulation  
- Abstraction  
- Event-driven programming using a graphics library  

---

 🧱 Core Features (Planned / In Development)

- Grid-based map system  
- Enemy path movement system  
- Multiple enemy types with different behaviors  
- Multiple tower types with unique attack mechanics  
- Wave-based gameplay system  
- Economy system (gold and tower placement cost)  
- Lives system and game over condition  
- Graphical interface using SFML  

---

 🛠️ Technologies Used

- C++  
- SFML (Simple and Fast Multimedia Library)  
- Visual Studio  

---

 🚀 How to Run

1. Open the project in Visual Studio  
2. Ensure SFML is properly installed and linked  
3. Build solution (x64 Debug mode recommended)  
4. Run the program
